## 从下单到收货

1. 下单前查看具体商品说明，确认需要手机号与接码地址，还是 session、json、tdata 文件。不同商品支持不同交付方式，不代表每件商品都包含全部格式，也不保证一定收到短信。格式不熟悉时，先阅读[登录与交付格式教程](https://xixipifa.com/articles/telegram-login-delivery-formats-zh)。
2. 付款后回到原订单，查看账号资料、交付文件或领取入口，核对商品与数量。账号资料仅自己保管，避免在公开仓库、截图或聊天群中暴露。
3. 首次登录前开始录像，完整记录手动登录过程，禁止使用脚本登录。保留订单号和原始交付资料，发现异常时方便核对。
4. 登录后按账号当前可用能力，尽快修改两步验证密码和恢复邮箱；再核对会员状态与有效期。遇到问题保留现场信息，通过网站客服提交订单号与录像。
